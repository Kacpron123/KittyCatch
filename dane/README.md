# Dane wejściowe

`config/` zawiera aktualny balans i mapę. Identyczne pliki wykonawcze znajdują się w `kod/godot_game/config/`. `scenariusze.json` opisuje podział trening–test i profile. `przykladowa_fala_mieszana.json` zawiera harmonogram wykorzystany w rzeczywistym meczu Godota. Faktyczne wysłanie jednostki nadal wymaga energii.
