- `tabele/`: CSV, w tym 2880 ocen osobników i 90 statystyk populacji.

- `animacje/`: mecz Godota, lokalna symulacja i ewolucja.
- `prezentacja/`: PPTX, notatki i aktualna pomoc PDF.
- `eksperyment/`: kompletny zapis eksperymentu z konfiguracją, genami i telemetrią.
